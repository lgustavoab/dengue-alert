# Dengue Alert

Projeto de Trabalho de Conclusão de Curso em Ciência de Dados voltado à investigação do potencial de dados epidemiológicos e meteorológicos para antecipar aumentos no risco de dengue em municípios brasileiros.

## Objetivo

Desenvolver e avaliar um sistema preditivo capaz de estimar o risco de aumento de dengue em horizontes futuros utilizando histórico epidemiológico, características temporais e variáveis meteorológicas.

## Período de estudo

2016–2025.

## Fontes principais

- SINAN — registros de dengue;
- IBGE — municípios, população e geografia;
- ERA5-Land / Copernicus — dados meteorológicos.

## Tecnologias

- Python 3.13
- uv
- Pandas
- PyArrow / Parquet
- Scikit-learn
- Next.js / React / TypeScript

## Status

Projeto em desenvolvimento. A etapa de auditoria e preparação das fontes foi concluída e a arquitetura definitiva do pipeline está sendo consolidada.
